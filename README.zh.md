# Maquill

Maquill 是一个通过 LLM 辅助写作的 Obsidian 插件。Maquill 既有 Magic Quill 的含义，也有神笔马良的意象。

## 使用方法

- 克隆此仓库。
- 确保你的 NodeJS 至少为 v16（`node --version`）。
- 运行 `npm i` 或 `yarn` 安装依赖。
- 运行 `npm run dev` 在监听模式下开始编译。

## 手动安装插件

- 将 `main.js`、`styles.css`、`manifest.json` 复制到你的库的插件目录: VaultFolder/.obsidian/plugins/your-plugin-id/
